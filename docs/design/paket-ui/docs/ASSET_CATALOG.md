# SUARA — Katalog aset individual

- `assets/logo/` — logo asli yang pengguna berikan, favicon berbagai ukuran, wordmark editable.
- `assets/mascot/` — tiap pose Tunas PNG terpisah dengan background transparan, diturunkan dari sumber karakter yang sama; `tunas-original-scene.png` adalah ilustrasi lengkap dengan latar **bukan** PNG transparan.
- `assets/scenes/` — ilustrasi balai desa, persawahan, jembatan, dan dekorasi lanskap.
- `assets/icons/` — 16 ikon UI SVG terpisah.
- `assets/reference/` — referensi saja, **jangan** dipakai langsung sebagai komponen UI.

**Penting**: pose PNG adalah ekstraksi/upscale dari board referensi, bukan hasil ilustrasi vektor orisinal yang sepenuhnya editable. Untuk animasi Rive/Lottie diperlukan ilustrasi source-layer baru. Jangan mengklaim pose PNG sebagai SVG editable.
